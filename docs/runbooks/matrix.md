# Runbook: Matrix (jackpoint.xyz)

Matrix homeserver for `jackpoint.xyz` on the `cloud` cluster, namespace
`matrix`. Deployed by ess-helm `matrix-stack` via
`cloud/applications/matrix.cd.yaml`. Extra resources live in `cloud/matrix/`.

## Components

| Component | Host | Purpose |
| --- | --- | --- |
| well-known (haproxy) | `jackpoint.xyz` | `/.well-known/matrix/{server,client}` delegate to `matrix.jackpoint.xyz:443` |
| Synapse | `matrix.jackpoint.xyz` | Homeserver, client and federation API |
| MAS | `account.jackpoint.xyz` | Login, registration, password reset, QR login |
| Element Web | `chat.jackpoint.xyz` | Web client |
| Element Admin | `admin.jackpoint.xyz` | Users, rooms, registration tokens |
| lk-jwt-service | `mrtc.jackpoint.xyz` | Issues LiveKit tokens to room members (appservice) |
| LiveKit SFU | `mrtc.jackpoint.xyz`, `turn.jackpoint.xyz` | Call media, embedded TURN |
| Valkey | internal | lk-jwt-service and LiveKit state, no auth |
| CNPG `matrix-postgres` | internal | Databases `synapse` and `mas` |

`server_name` is embedded in every user and room ID and cannot be changed.

## Network paths

| Traffic | Path |
| --- | --- |
| HTTPS (all hosts) | Hetzner LB (TCP) → traefik → Ingress |
| Call media (UDP) | Worker public IP, NodePort `30002/udp` |
| TURN (UDP) | Worker public IP, NodePort `30004/udp`; also the clients' STUN server |
| TURN/TLS | `turn.jackpoint.xyz:443` → traefik SNI passthrough (`ingress-routes/matrix-turn-tls.yaml`) → LiveKit, which terminates TLS |
| ICE/TCP | Disabled (`rtc.tcp_port: 0`); the LB cannot carry it |

The Hetzner LB is TCP only, so UDP bypasses it.

## External setup

- **Firewall:** open `30002/udp` and `30004/udp` on the workers, from anywhere.
- **Mail:** an SMTP account for `noreply@jackpoint.xyz` (STARTTLS, port 587), with the mail DNS records (MX, SPF, DKIM, DMARC) in place.
- **Worker sysctl:** set `net.core.rmem_max` and `net.core.wmem_max` to at least `16777216`. LiveKit requests 16 MiB UDP socket buffers.

## Storage

| Data | Storage |
| --- | --- |
| Synapse media | `hcloud-volumes` (location bound); Synapse pinned to `fsn1` |
| Postgres data and WAL | `longhorn-local` (1 replica, strict-local); CNPG replicates between its 2 instances, both pinned to `fsn1` next to Synapse |
| Postgres backups | barman-cloud plugin to S3, WAL archiving plus a daily ScheduledBackup |

Synapse retention:

- Remote media cache expires after 90d and is refetched on demand. Local uploads are kept.
- `forget_rooms_on_leave: true`.

Postgres across regions makes every request slow. Keep Synapse and both Postgres instances in `fsn1`.

## Configuration notes

| Setting | Reason |
| --- | --- |
| MAS password schemes: v1 `bcrypt`, v2 `argon2id` | v1 verifies hashes imported from Synapse; new and rehashed passwords use v2 |
| `password_registration_token_required: true` | Registration only with a token |
| `password_recovery_enabled: true` | Needs the email config (`matrix-mas-email`) |
| `user_directory.search_all_users: true` | Local users can find each other without sharing a room |
| `turn.enabled: true` | Clients otherwise get Google/Twilio STUN servers |

Federation is open (no allow list). Remote users reach local users via `@user:jackpoint.xyz`.

## Operations

**Create a user directly:**

```sh
kubectl --context private.cloud -n matrix exec -it deploy/matrix-matrix-authentication-service -- \
  mas-cli manage register-user
kubectl --context private.cloud -n matrix exec deploy/matrix-matrix-authentication-service -- \
  mas-cli manage promote-admin <username>
```

**Invite someone:**

1. Create a registration token in Element Admin (`admin.jackpoint.xyz`).
2. Send it to them; they register at `chat.jackpoint.xyz`.
3. Email verification is required.

Usernames are lowercase `a-z 0-9 . _ = - /`.
